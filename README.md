# מילון אנגלית

אתר לתרגול 3,695 מילים באנגלית, מחולקות ל־10 רמות קושי וקבוצות של 50 מילים.
בוחן קריאה ובוחן שמיעה, משפט לדוגמה לכל מילה, כרטיסיות, רשימת טעויות לכל קבוצה,
וסנכרון התקדמות בין מכשירים דרך Firebase.

- `index.html` – האתר עצמו (זה הקובץ ש־Netlify מציג).
- `src/template.html` – הקוד של האתר.
- `src/words.json` – המילים: [מילה, פירושים, רמה, משפט לדוגמה].
- `build.py` – בונה מחדש את `index.html` מתוך `src/` (`python3 build.py`).
