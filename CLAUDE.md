# English dictionary site

`index.html` is generated. Edit files in `src/`, then run `python3 build.py`, commit and push to `main` (Netlify deploys from it).

- `src/template.html` – the app (HTML/CSS/JS); `__DATA__` is replaced with `src/words.json`.
- Words: `[english, [hebrew…], level 1–10, example sentence]`; for a word with several meanings the sentence is a list, one sentence per meaning (same order). In the app each meaning becomes its own card (id `word#k` when a word has several meanings, else `word`) that asks that meaning and shows the others; sibling cards are spread about one group apart. Groups are 50 cards per level.
- Each entry in the Hebrew list is one meaning. A line from the original dictionary stays as written (commas kept) unless it mixes completely different meanings, which are split; separate dictionary lines with the same meaning are joined with " / ". A ";" inside a dictionary line separates meanings (split), commas stay. A dictionary line naming several English words (e.g. "know, knew", "leaf (leaves)") becomes one entry per English word, about one group apart; such entries carry a 5th field `{id, src}` (stable id "line|word", old card ids for marks).
- Quiz: one input line, multi-select options (one option per meaning plus one similar-looking wrong meaning), score per meaning, feedback is only "נכון!" / "לא נכון", then the user marks "ידעתי / לא ידעתי" (these buttons also sit under "הצגת אפשרויות", to mark without opening the options). Group and level screens offer quizzes per marking category (✗ / unmarked / ✓; session keys `N|U|Y` + group or level key); a category with no words left drops its unfinished quiz.
- Per-word "know" state lives in localStorage `dictKnow` and syncs via Firestore (project `english-dictionary-452b4`, collection `dictionary`, one fixed document `d-kZzMHDu3fpCjwyFCqiU9ys` for all devices; sync merges by timestamps).
- Audio: English words and sentences play from recorded mp3s (`audio/w`, `audio/s`, file name = FNV-1a hash of the exact text, see `tools/audio_util.py`; generate missing ones with `python3 tools/gen_audio.py w|s`). An `<audio>` element plays even on iPhone silent mode; the app tries `audio/` next to the page, then the GitHub repo via jsDelivr / raw.githubusercontent, then device speech synthesis. After changing words or sentences, generate the audio before pushing.
- Voice mode (mic button in the quiz, meant for driving): plays the English word from its mp3, reads the Hebrew parts with he-IL speech synthesis and listens with Web Speech recognition in Hebrew; commands: numbers / option text, "ידעתי", "לא ידעתי", "חזור", "עצור". Script per word: word, sentence, "פירושים אחרים של המילה: אחד - …", "מה הפירוש הנוסף?", listen; "מה הפירוש הנכון? אחד - … שתיים - …", listen for the number; "נכון!/לא נכון. ידעת או לא ידעת?", listen, next word. Gaps are short inside the flow (a pause only at start).
- Navigation: level and group screens have a search box (English or Hebrew) and a ✓/✗ word list (`S.wl` = level|group); a house button returns to the main screen; swiping right-to-left presses the screen's back button.
- Quiz arrows beside the word move between words; each word keeps its own state (`Q.st[index]`: typed text, options, answer), so a skipped word stays unanswered. Marking moves to the next unmarked word; when none is left after it, the quiz ends. Quiz order is reshuffled on every start (`pickList`: level order kept, shuffled inside each level, repeated English words at least 300 cards apart, or as far apart as the list allows). The main screen has a search box and quizzes on all words (key `ALL`, plus N/U/Y categories).
- "מצב רץ" auto-play mode (button in the quiz and cards top bar, localStorage `dictAuto`): reads each new word aloud when moving to it; otherwise words play only from a speaker button (except the listening quiz and voice mode).
- The example sentence sits right under the word, centered, and opens only when tapped (in the quiz too, even after answering); its "תרגום לעברית" button and the translation are centered under it; in מצב רץ, showing it also reads it. Marking-category quiz buttons (✗/✓) use the same red/green outlined style as the ידעתי / לא ידעתי buttons. A floating ↑ button returns to the top of long pages.
- Daily counter: every ✓/✗ mark logs the card id under the day (`dictDays` = {"YYYY-MM-DD": [ids]}, a day starts at 05:00, synced by union). Main screen shows today's count toward the goal of 240 (`GOAL`); tapping it opens the per-day history; the quiz tag shows "היום n/240".
- Extras: `src/extra/*.json` are merged by build.py (field by field, files in name order, so later `z*.json` rewrites override `b*.json`; `zw*.json` hold use/tip rewrites, `zz[0-9]*.json` the tips, `zzz*.json` (sorted last) the final `use` for every card plus tip overrides) into `EXTRA` (`__EXTRA__`), keyed by card id: `{tr, use, tip}` = Hebrew translation of the example sentence, Hebrew usage notes ("📌 דגשים"), memory tip ("💡 טיפ לזכירה": an association bridge from something familiar – a Hebrew sound-alike, loanword, app or brand, or English root – to the meaning, e.g. post = פוסט באינסטגרם → עמוד). In the quiz they are hidden until "בדיקה" and then shown in full (`xfull`, no buttons); elsewhere (cards, word lists) both buttons show and open a box with one bullet per line (split on newlines and sentence ends; English runs set in `<bdi>`). `use` = numbered grammar/context points (one per `\n` line, rendered as a numbered list, each ≥8 chars with Hebrew): what comes before/after (noun, ing, which preposition), irregular forms, register (formal/spoken), which subjects it describes (e.g. prestigious → institutions, not people), confusable words. `tip` must not be "the same word inside an English phrase" unless that phrase is everyday-familiar. Write both in Hebrew. New cards need an entry. The personal-notes UI was removed (old `dictNotes` data still syncs, unused).
- Private lesson ("מילים לשיעור פרטי"): `src/private.json` = `{write, lists:[{n, w:[[english, hebrew, example sentence]…]}]}`, injected as `PRIV` (`__PRIVATE__`). Shown as its own section (internal level `PL`=11, one group per list, group session keys `GP<n>`), card ids `p<n>|<english>`, with all the usual features (cards, quizzes, marks, word list, audio, extras in `src/extra/p<n>.json`). Every week the user sends 2 lists: replace `lists` with them (older list first) and set `write` to the newer one's number; add extras + example sentences, run `gen_audio.py w` and `s`. Never touch `dictSent`.
- Sentences page (screen `sent`, for list `write`): per word an English sentence and an optional Hebrew meaning, auto-growing; done = English written; sticky counter/bar + save status; export = numbered "sentence (word)" lines with copy and missing count; speaker plays the word mp3 at 0.85 speed and is colored while playing. Stored in `SENT` (localStorage `dictSent`, synced field `sent`: `{id:{en:[text,t],he:[text,t]}}`), merged per field newest-wins and never pruned, so old lists' sentences stay. Push reads the account doc, merges, and writes with an `updateTime` precondition (retries on conflict); the sentences page polls every 4 s and updates fields in place (not the one being typed in). Every page's scroll position is saved (`dictScroll`) and restored after reload.
