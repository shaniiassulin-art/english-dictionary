# English dictionary site

`index.html` is generated. Edit files in `src/`, then run `python3 build.py`, commit and push to `main` (Netlify deploys from it).

- `src/head.html` – the page head; the app icon (apple-touch-icon 180px + 64px favicon, inlined PNGs: two tilted cards "A" white / "א" light blue on the dark blue accent gradient).
- `src/template.html` – the app (HTML/CSS/JS); `__DATA__` is replaced with `src/words.json`; `/*__AMIRAM_JS__*/` with `src/amiram.js`; build.py also copies `src/amiram.json` to `amiram.json` (fetched at runtime).
- Words: `[english, [hebrew…], level 1–10, example sentence]`; for a word with several meanings the sentence is a list, one sentence per meaning (same order). In the app each meaning becomes its own card (id `word#k` when a word has several meanings, else `word`) that asks that meaning and shows the others; sibling cards are spread about one group apart. Groups are 50 cards per level.
- Each entry in the Hebrew list is one meaning. A line from the original dictionary stays as written (commas kept) unless it mixes completely different meanings, which are split; separate dictionary lines with the same meaning are joined with " / ". A ";" inside a dictionary line separates meanings (split), commas stay. A dictionary line naming several English words (e.g. "know, knew", "leaf (leaves)") becomes one entry per English word, about one group apart; such entries carry a 5th field `{id, src}` (stable id "line|word", old card ids for marks).
- Quiz: one input line, multi-select options (one option per meaning plus one similar-looking wrong meaning), score per meaning, feedback is only "נכון!" / "לא נכון" (a right option she missed is shown solid green, thick border, bold, with a green "התשובה הנכונה" tag – `.opt.missed`/`.rtag`), then the user marks "ידעתי / לא ידעתי" (these buttons also sit under "הצגת אפשרויות"; pressed before answering, they save the mark and open the answer as if checked – right options, tip, notes, no נכון/לא נכון (`Q.skip`) – with "למילה הבאה" to go on; in voice mode they move on directly). The reading/listening switch (`modeSeg`, `S.mode`) stays visible on an unfinished quiz too; resuming any quiz (`resumeQuiz`) continues from the same word in the currently chosen mode. Resume / category rows keep even spacing: the "עדכון" / "התחלה מחדש" links sit exactly midway (no link padding, row gap = panel gap). Group and level screens offer quizzes per marking category (✗ / unmarked / ✓; session keys `N|U|Y` + group or level key); a category with no words left drops its unfinished quiz. An unfinished category quiz whose words changed category shows "עדכון (n עברו קטגוריה, m חדשות)" (`catDiff`/`catUpdate`): drops words that left, appends words that joined, stays on the same word (or the next one still in the category) and keeps each word's state.
- Per-word "know" state lives in localStorage `dictKnow` and syncs via Firestore (project `english-dictionary-452b4`, collection `dictionary`, one fixed document `d-kZzMHDu3fpCjwyFCqiU9ys` for all devices; sync merges by timestamps).
- Audio: English words and sentences play from recorded mp3s (`audio/w`, `audio/s`, file name = FNV-1a hash of the exact text, see `tools/audio_util.py`; generate missing ones with `python3 tools/gen_audio.py w|s`). An `<audio>` element plays even on iPhone silent mode; the app tries `audio/` next to the page, then the GitHub repo via jsDelivr / raw.githubusercontent, then device speech synthesis. After changing words or sentences, generate the audio before pushing.
- Voice mode (mic button in the quiz, meant for driving): plays the English word from its mp3, reads the Hebrew parts with he-IL speech synthesis and listens with Web Speech recognition in Hebrew; commands: numbers / option text, "ידעתי", "לא ידעתי", "חזור", "עצור". Script per word: word, sentence, "פירושים אחרים של המילה: אחד - …", "מה הפירוש הנוסף?", listen; "מה הפירוש הנכון? אחד - … שתיים - …", listen for the number; "נכון!/לא נכון. ידעת או לא ידעת?", listen, next word. Kept fast: the next 3 words' mp3s (word + sentence) are prefetched into blob URLs (`PRE`, `prefetchWords`), Hebrew speech rate 1.1, short gaps (200 ms after the mic, 60+90 ms around the beep), listening stops 250 ms after a recognisable answer (`ask(ms, ok)`) or 900 ms after speech goes quiet instead of waiting for the final result; start says only "מתחילים".
- מצב רכב (car mode): a toggle at the top of the quiz settings (`CARON`, localStorage `dictCar`), chosen before the quiz type; turning it on starts car mode right away (voice included) on that panel's words – the whole group / level / all words, from the saved place if there is one (bound in `bindQuizPanel`); turning it off just switches back; while on, every start button (whole group/level/all and the ✗/unmarked/✓ categories) opens screen `car` instead of a quiz: word + speaker, example sentence + תרגום לעברית, the card's Hebrew meaning, tip + notes (`xfull`). It plays without stopping – word mp3, sentence mp3, a 4 s pause to think (`CARWAIT`; meaning and tip hidden as "🤔 מה הפירוש?" until then, `CAR.rev`, or "הצגת התשובה"), Hebrew meaning (the tip is not read aloud) – then waits (`CAR.wait`, a soft tone, "סמני אם ידעת…") until ✗/✓ is marked, which plays the next word; Hebrew meaning at CRATE+.15 and tip at `CRATE` (⚙ קול ומהירות: איטית .8 / רגילה .95 / מהירה 1.1, localStorage `dictCarRate`) and the Hebrew voice picker (`heVoice`/`pickHe`, localStorage `dictHeVoice` = voiceURI; one entry per voice name + quality (`heVoices`; iPhone gives the same Carmit twice as compact/super-compact, which sound the same – super-compact is dropped when a better one exists), labelled `heLabel`: plain "כרמית", or (משופר ⭐) / (פרימיום ⭐⭐); plus Gemini voices (`GEMV`: 10 chosen voices – 6 women, 4 men – labelled by character, value `gem:<name>` → `heGem`; a second picker `enSel` (localStorage `dictEnVoice`, `enGem`) can read the English word + sentence in car mode with a Gemini voice instead of the recordings, recordings as fallback; settings close with ✕ in their header, "סגירת ההגדרות" at the bottom, or the ⚙ bar button which turns into ✕ while open): in car mode Hebrew meaning and tip are read by Gemini TTS (`gemAudio`/`gemSay`, models `GTTSM` with last winner `dictGemTtsModel` first, 404s in `dictGemTtsGone`, PCM→WAV, kept in Cache Storage `gemtts`, the current and next word made ahead by `gemPre`, played through the `<audio>` element via `PRE`; falls back to the device voice on error/quota/9 s, with the reason in `#gemSt`), default the best quality; also used by voice mode) with iPhone instructions to download כרמית (משופר); bar (kept simple on purpose): ✗ לא ידעתי / ✓ ידעתי (each "ועוברים למילה הבאה"), → מילה קודמת / ⏸ עצירת ההקראה / ▶ המשך (or להקריא שוב while waiting) / ← מילה הבאה (`carGo`: `CAR.cur` = the word being studied, `CAR.i` = the word on screen; moving to another word only shows it with its answer, no reading, a line "מסתכלת על מילה…" and ▶ "חזרה למילה הנוכחית"; coming back to `CAR.cur` reads it again from the start; ✓/✗ marks the word on screen, then on the studied word goes on to the next one, otherwise returns to the studied word and reads it; progress is saved at `CAR.cur`). Turning car mode on in a panel with an unfinished quiz (newer than any car progress) continues that quiz's words from the same word / ⚙ – no outline on the part being read; the screen is compact (`.car …` overrides: word and speaker on one row, tight sentence/meaning/tip boxes, smaller bar; the steering-wheel hint lives in ⚙) so meaning + tip fit without scrolling; once the meaning shows, the tip and the 📌 דגשים box are both open (`carX`; the notes can be folded with ▾, kept per word in `CAR.useShut`); no microphone; on return from another app / locked screen (`visibilitychange`; also when it was on while hidden – `CAR.hidOn`, incl. a Media Session pause while hidden) `carRestart` says "מתחילים" and replays the current word from its start (think pause again); after a reload on the car screen (iPhone never lets a fresh page start sound by itself) or when starting by itself fails, a full-screen "▶ לחצי כדי להמשיך" overlay (`CAR.needTap`, `#cTap`) appears and its tap runs `carRestart(true)` (speech begins inside the tap, no delay); the device voice is unlocked once per start with "מתחילים" inside the tap, and the first word starts only after it ends (device voice + recording starting together cut the recording on iPhone); `playFile` resumes a recording that iPhone pauses by itself (`onpause` → play again after 0.5 s). Hebrew is still device speech, so it only runs with the page in the foreground (no Hebrew TTS model reachable from the build container – HuggingFace is blocked – to pre-record Hebrew mp3s). ✗ לא ידעתי / ✓ ידעתי buttons (`carKnow`: saves the mark, shows a big green ✓ ידעתי / red ✗ לא ידעתי with the word for 1.4 s (`knowFlash`, `#kflash` on body), short tone, next word); steering-wheel/headphone ⏭ = ידעתי, ⏮ = לא ידעתי, ⏯ = pause/play. Steering-wheel/headphone buttons via Media Session; iPhone fires a Media Session "pause" by itself when the audio switches between the mp3s and the Hebrew device voice, so a pause within 2.5 s of a part starting (`AUDT`, set in `playFile`/`say`/`sayNow`) is ignored; progress saved as session `C`+key (`saveCar`), shown as "המשך".
- Level and group screens share one layout and order: (private level: ✍ sentences button) → search → quiz panel → marking-category quizzes (or a hint) → ✓/✗ word list button → "תרגול בכרטיסיות" / "המשך כרטיסיות" with "התחלה מחדש של הכרטיסיות" under it (deletes the saved progress and starts a fresh shuffle) (`cardsBtn`/`bindCards`, also for a whole level; progress under `F`+key so it never mixes with car mode's `C`+key – an old cards session under `C` is still read; `C.from` returns to the screen it came from) → (level) the groups. The sentence-check details end with "סגירת ההערות ▴".
- The unfinished-quiz panel has no progress bar (only "עצרת במילה…").
- Phones (≤420px): body 16px, side padding 14px, tighter panels and car toggle, one-line segmented buttons and short hint texts – avoid needless line breaks (home level rows: "N מילים · יודעת k · לא סומנו u", the group count only before any marks, `.lvd` one line). Page spacing: on every screen except quiz/car, blocks are spaced only by the `.screen` gap (direct children have no margins; empty blocks like an empty `#srchRes` are hidden).
- Text fields (inputs, textareas, selects) show only an accent border when focused – no outline ring.
- Word-list rows (`wordRow`): the 💡/📌 buttons and their opened boxes sit on their own full-width row under the word (`.words li>.xwrap`), so the text isn't squeezed.
- Navigation: level and group screens have a search box (English or Hebrew) and a ✓/✗ word list (`S.wl` = level|group); a house button returns to the main screen; swiping right-to-left presses the screen's back button.
- All arrow icons are SVGs centered in their buttons (`.ai`: quiz and car prev/next, ↑ to top, list chevrons, "למילה הבאה", fix rows; the back link's arrow is a CSS mask). Quiz arrows beside the word move between words; the example sentence line has extra space below it before the answer box; each word keeps its own state (`Q.st[index]`: typed text, options, answer), so a skipped word stays unanswered. Marking moves to the next unmarked word; when none is left after it, the quiz ends. Quiz order is reshuffled on every start (`pickList`: level order kept, shuffled inside each level, repeated English words at least 300 cards apart, or as far apart as the list allows). The main screen has a search box and quizzes on all words (key `ALL`, plus N/U/Y categories).
- "מצב רץ" auto-play mode (button in the quiz and cards top bar, localStorage `dictAuto`): reads each new word aloud when moving to it; otherwise words play only from a speaker button (except the listening quiz and voice mode).
- The example sentence sits right under the word, centered, and opens only when tapped (in the quiz too, even after answering); its "תרגום לעברית" button and the translation are centered under it; in מצב רץ, showing it also reads it. Marking-category quiz buttons (✗/✓) use the same red/green outlined style as the ידעתי / לא ידעתי buttons. A floating ↑ button (bottom-left) returns to the top of long pages. A refresh button (SVG arrow `.re-ic` that turns smoothly inside the still button while reloading) sits in every screen's top bar next to the house (`HOME` includes it, `.reload-top`), on the home screen at the top beside the title (the search box, full width, comes right under the title / sync line, above "להמשיך מאיפה שעצרת"), in the sentences page's sticky header; any `[data-reload]` (`doReload`) saves (scroll + pending sync push) and reloads with a cache-busting `?v=` address so the newest version loads.
- Daily counter: every ✓/✗ mark logs the card id under the day (`dictDays` = {"YYYY-MM-DD": [ids]}, a day starts at 05:00, synced by union). Main screen shows today's count toward the goal of 240 (`GOAL`); tapping it opens the per-day history; the quiz tag shows "היום n/240".
- Extras: `src/extra/*.json` are merged by build.py (field by field, files in name order, so later `z*.json` rewrites override `b*.json`; `zw*.json` hold use/tip rewrites, `zz[0-9]*.json` the tips, `zzz*.json` (sorted last) the final `use` for every card plus tip overrides) into `EXTRA` (`__EXTRA__`), keyed by card id: `{tr, use, tip}` = Hebrew translation of the example sentence, Hebrew usage notes ("📌 דגשים"), memory tip ("💡 טיפ לזכירה": an association bridge from something familiar – a Hebrew sound-alike, loanword, app or brand, or English root – to the meaning, e.g. post = פוסט באינסטגרם → עמוד). In the quiz they are hidden until "בדיקה" and then shown in full (`xfull`, no buttons); elsewhere (cards, word lists) both buttons show and open a box with one bullet per line (split on newlines and sentence ends; English runs set in `<bdi>`; arrows → ⇒ ➡ in the Hebrew parts are flipped to ← ⇐ ⬅ so they point in RTL reading direction). `use` = numbered grammar/context points (one per `\n` line, rendered as a numbered list, each ≥8 chars with Hebrew): what comes before/after (noun, ing, which preposition), irregular forms, register (formal/spoken), which subjects it describes (e.g. prestigious → institutions, not people), confusable words. `tip` must not be "the same word inside an English phrase" unless that phrase is everyday-familiar. Assume the user doesn't know English: a tip may use only the target word itself plus Hebrew sound-alikes, loanwords common in spoken Hebrew (לייק, טיימר, פרופורציה…) or well-known brands/apps – no other English words, roots or phrases, and no high-register Hebrew. Final tips live in `zzzz*.json` (sorted after `zzz*`; `zzzzp.json` = private cards, `zzzzz.json` = last fixes). Write both in Hebrew. New cards need an entry. The personal-notes UI was removed (old `dictNotes` data still syncs, unused).
- Private lesson ("מילים לשיעור פרטי"): `src/private.json` = `{write, lists:[{n, d?, w:[[english, hebrew, example sentence]…]}]}` (`d` = the number shown, `LN(L)`, when a list is renumbered – `n` stays because it is in card ids, extras keys and sentence ids; lists 13/14 are shown as 14/15), injected as `PRIV` (`__PRIVATE__`). Shown as its own section (internal level `PL`=11, one group per list), card ids `pw<week>|<n>|<english>` (`week` in private.json = the date the lists were sent, so each week's lists are fresh copies with their own ✓/✗ marks; extras keyed `p<n>|<english>` via `w.xid`), separate from the dictionary: never inherit dictionary marks, not in the main-screen counts / search / ALL quizzes (`DW` = dictionary cards) and not in the daily goal (`isPrivId`), session keys `GP<week>-<n>` / `LP<week>`, with all the usual features (cards, quizzes, marks, word list, audio, extras in `src/extra/p<n>.json`). Every week the user sends 2 lists: replace `lists` with them (older list first) and set `write` to the newer one's number and `week` to the new date; add extras + example sentences, run `gen_audio.py w` and `s`. Never touch `dictSent`.
- Sentences page (screen `sent`, for list `write`): per word an English sentence and an optional Hebrew meaning, auto-growing; done = English written; sticky counter/bar + save status; export = one "sentence (word)" per line, no numbers, with copy and missing count; the export panel also lists the words left-to-right ("english - hebrew", short hyphen) with "העתקה עם פירושים" / "רק באנגלית" (`expWordsText`, first line "מילים לאמירנט #<shown number>"); speaker plays the word mp3 at 0.85 speed and is colored while playing. Stored in `SENT` (localStorage `dictSent`, synced field `sent`: `{id:{en:[text,t],he:[text,t]}}`), merged per field newest-wins and never pruned, so old lists' sentences stay. Push reads the account doc, merges, and writes with an `updateTime` precondition (retries on conflict); the sentences page polls every 4 s and updates fields in place (not the one being typed in); refreshes write to the DOM only when something changed (`setTxt`/`setHtml`/`setCls`) – any DOM change closes iPhone's spelling-suggestions bubble – and the textareas have `touch-action:auto`, spellcheck/autocorrect on. Each sentence has "🔍 בדיקת המשפט" (`checkSentence`) – smart check only (the regular LanguageTool spelling check was removed at the user's request): Gemini with the user's free Google AI Studio key – built in scrambled as `GK0` (default), overridable in the "🧠 בדיקה חכמה" box `sentAiBox` or by a `#gk=<key>` link (`setGKey`: localStorage `dictGemKey` + `dictGemKeyT` [key,t], synced as field `gk`, newest wins;
